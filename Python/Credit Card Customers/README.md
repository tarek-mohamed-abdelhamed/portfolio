# 💳 Credit Card Customers Analysis  

## 📘 Project Overview  
A Python-based data analysis project using **Pandas, NumPy, Matplotlib, and Seaborn** in **Jupyter Notebook** to explore customer behavior, spending patterns, and attrition trends from a credit card dataset.  

---

## 🧹 Data Cleaning  
- Removed unnecessary columns (`CLIENTNUM`, `Naive_Bayes`).  
- Applied business-friendly column names for clarity.  
- Checked data types, missing values, and duplicates.  

---

## 🧮 Data Analysis  
Performed aggregation and statistical analysis to explore:  
- Average credit limit by card type.  
- Total transaction amount and count per customer category.  
- Attrition rate by gender, income, and card category.  

---

## 📊 Visualization  
Created visual insights using **Matplotlib** and **Seaborn**:  
- Distributions of age, education, and income.  
- Spending behavior and utilization ratios.  
- Attrition patterns and correlations via heatmaps.  

---

## 💡 Key Insights  
- Most customers use **Blue** cards with moderate spending levels.  
- Higher attrition among customers with low income and small credit limits.  
- Strong correlation between transaction amount, credit limit, and utilization ratio.  

---

## 🧠 Skills Gained  
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn  
**Techniques:** Data cleaning, grouping & aggregation, visualization, and insight extraction.
