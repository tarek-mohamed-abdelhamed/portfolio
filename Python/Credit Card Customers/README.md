# 💳 Credit Card Customers Analysis  

## 📘 Project Overview  
A Python-based data analysis project using **Pandas, NumPy, Matplotlib, and Seaborn** in **Jupyter Notebook** to explore customer behavior, spending patterns, and attrition trends using credit card data.

---

## 🧹 Data Cleaning  
- Removed unnecessary columns (`CLIENTNUM`, `Naive_Bayes`)  
- Renamed columns to business-friendly names  
- Checked data types, missing values, and duplicates  

---

## 🧮 Data Analysis  
Used aggregation and statistical methods to analyze:  
- Average credit limit by card type  
- Total transaction amounts and counts per customer group  
- Attrition rate by gender, income, and card category  

---

## 📊 Visualization  
Used **Matplotlib** and **Seaborn** to create visuals such as:  
- Distributions of age, income, and education  
- Behavior by card usage and spending  
- Attrition patterns and correlation heatmaps  

---

## 💡 Key Insights  
- Most customers use **Blue** cards with moderate spending  
- Higher attrition among lower income and lower credit limit customers  
- Strong relationships between transaction amount, credit limit, and utilization  

---

## 🧠 Skills Gained  
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn  
**Techniques:** Data cleaning, aggregation, visualization, insight extraction
