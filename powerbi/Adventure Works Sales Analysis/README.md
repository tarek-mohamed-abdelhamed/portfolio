<h2>📊 Power BI Project – Sales Analysis </h2>
<p>Transforming raw SQL Server data into a clean, analytical Power BI dashboard using a <strong>Star Schema</strong> model.</p>

<hr>

<h3>📁 Project Overview</h3>
<p>
This project represents a major milestone in my BI journey. I developed an interactive sales dashboard by executing all modeling and ETL tasks within 
<strong>SQL Server</strong> — creating dimensions, views, and merging tables — before importing to Power BI for visualization and reporting.
</p>

<h3>🧩 Data Modeling & SQL Work</h3>
<ul>
  <li>Fully designed <strong>Star Schema</strong> in SQL Server.</li>
  <li>Created dimension tables: <em>Product, Subcategory, Category, Date, Salesperson, Status, Ship Method, Territory</em>.</li>
  <li>Built the <strong>Fact Sales</strong> table.</li>
  <li>Performed joins and merges across tables for unified data.</li>
  <li>Defined <strong>SQL Views</strong> to streamline and standardize data for Power BI.</li>
</ul>

<h3>🧮 Power BI & DAX</h3>
<ul>
  <li>Imported SQL views into Power BI and established relationships.</li>
  <li>Created <strong>DAX Measures</strong>: Orders, Subtotal, Tax, Freight, Total Due, Quantity.</li>
  <li>Used <code>USERELATIONSHIP()</code> to manage multiple date relationships for analysis.</li>
</ul>

<h3>📈 Dashboard Highlights</h3>
<ul>
  <li><strong>Overview Page:</strong> Orders by Ship Method, Category, Status, and Top 10 Salespersons.</li>
  <li><strong>Performance Page:</strong> Decomposition Tree for Product → Subcategory → Category breakdown.</li>
  <li>Monthly trends: peaks in March & April, comparing Ship Date vs Due Date.</li>
</ul>

<h3>💡 Key Insights</h3>
<ul>
  <li><strong>Total Sales:</strong> $109.85M</li>
  <li><strong>Total Quantity:</strong> 275K units</li>
  <li><strong>100%</strong> of orders shipped successfully; <strong>87%</strong> via Truck Ground</li>
  <li>Top categories: <em>Bikes & Accessories</em></li>
  <li>Top-performing Salespersons: <em>Jillian Carson & Michael</em></li>
</ul>
